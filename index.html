Nuevo miembro

Registra la huella del socio con el lector USB antes de guardar. El sistema asocia el identificador que envía el lector al perfil; no imprime una credencial.
Se registra el pago y se imprime el ticket. Para cortesía, escribe 0.
El lector debe comparar la huella y enviar un identificador único como teclado USB HID. Escanea una sola vez por socio.

Registro con huella

1. Completa los datos del socio y el pago.
2. Selecciona el campo “Huella del socio”.
3. Pasa el dedo por el lector; el código recibido se asociará al perfil.
4. Guarda el registro. En el control de acceso, el mismo lector buscará al socio y marcará su entrada.

El prototipo no captura ni guarda imágenes o plantillas biométricas: el lector tendría que validar la huella y enviar un identificador. Esta integración provisional requiere modo teclado USB HID; muchos lectores necesitan el SDK del fabricante. Los identificadores se guardan en este navegador, sin sincronización. Habrá que probarlo cuando tengamos el modelo.
